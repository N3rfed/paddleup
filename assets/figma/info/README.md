# How to Play

The uploaded `How to play screen.svg` is preserved unchanged. The generated modal
retains its panel layers and removes the sample HUD, player list, and Roblox chrome
around it. The game displays that artwork over its actual running scene.

`Group.svg` supplies the help icon. `HowToPlay.luau` adds native Close and Play
buttons, H to toggle, controller navigation, and gameplay input blocking while open.
